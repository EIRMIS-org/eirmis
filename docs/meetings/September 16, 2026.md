## Discussion Points

### Event Management System Features

Andrei demonstrated the invitation response tracking feature of the Event Management System.

It was decided that the system can and would track different invitation responses, including:
- Accepted
- Declined
- Tentative
- No Response

The system would also include a guest list import feature using CSV files. Organizers can resend invitations and send nudges to guests who have not responded yet.

### Capacity Management
The capacity management features of the system were also discussed.

The system includes soft capacity warnings when the event is reaching its capacity. It also includes an approval workflow and allows organizers to handle requests for increasing the event headcount.

### Check-in System
The check-in process was discussed and demonstrated.

The system uses QR code scanning for checking in guests and includes duplicate verification to prevent the same guest from being checked in multiple times.

A manual name search is also available as a fallback for unscheduled guests or guests who cannot use the QR code.

### Public Event Registration
The landing page allows guests to register for public events.

The registration form can be customized to collect additional information from guests, including:

- Dietary preferences
- Accessibility requests
- Plus-one options

### Dashboard and System Monitoring

The dashboard includes different features for managing and monitoring events.

These include:

- RSVP management
- Organizer reports
- Waitlist tracking
- Email logs
- Audit logs
